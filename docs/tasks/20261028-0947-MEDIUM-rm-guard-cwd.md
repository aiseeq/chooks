# rm_guard: отказ на rm текущей папки Bash (workspace directory)

Статус: готово
Исполнитель: chooks-master

## Вход
Задание lead (Сон, обход harness) 28.10 ~09:50 CET, итог — git-admin. CC 2.1.x отказывает `rm -rf <путь>`, если путь — рабочая папка (cwd Bash), доп. рабочая папка или их родитель: «This command would remove a workspace directory … permission prompt timed out», окно ждёт 120 с. 4 случая в транскриптах с 26.10 (рабочий проект 26.10 12:16 UTC, graft 75f3c2fd 27.10 04:06, ~ 8d06de04 27.10 09:02, glint d4077e72 27.10 23:28), все после `cd` в папку под claude-tmp/scratchpad и затем `rm -rf` её же.

## Что сделать

## Приёмка
- `graft smoke` зелёный; новые тесты на 4 формы из транскриптов.
- Сухой прогон: 4 известных случая ловятся, ложных отказов на прочих rm в транскриптах нет (число до/после).

## Сделать
- Выяснить, что именно CC считает workspace directory (cwd Bash, additionalDirectories, родители) и есть ли в stdin хука текущий cwd Bash.
- rm_guard: отказ сразу, если цель rm — cwd Bash (или папка выше), с подсказкой «сначала cd в другую папку, потом rm». `cd /x && rm -rf <путь>` пропускать.
- Тест красный → зелёный, сухой прогон по транскриптам.
